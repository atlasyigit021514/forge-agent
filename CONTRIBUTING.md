# Contributing to Forge Agent

Thanks for helping improve Forge.

1. Open an issue for substantial behavior changes.
2. Keep pull requests focused and avoid unrelated formatting changes.
3. Add or update tests for behavioral changes.
4. Run `npm test` before opening a pull request.
5. Never commit `.agent-data`, `.env`, API keys, personal memory, or logs.
